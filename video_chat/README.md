# Lumi 視訊交友(極簡風格示範)

以「Craft Anything」的 Clean room 流程(只參考公開可見的版面型態,不讀取原站程式碼)重新設計的視訊交友網站,參考對象為 520cc.tw 這類視訊交友網站的常見結構,並改為極簡風格 UI。品牌、文案、主播資料皆為原創 / 虛構。

純 HTML + CSS + JavaScript,無需建置,直接開啟 `index.html` 即可。

## 功能

- 18+ 年齡確認頁
- 頂部導覽:首頁、排行榜、活動、我的收藏、搜尋、點數、登入;手機版漢堡選單
- 首頁:主視覺 + 在線人數、分類標籤(熱門 / 新人 / 聊天 / 唱歌 / 才藝 / 遊戲 / 旅行)、只看在線、排序
- 主播卡片:在線 / 通話中 / 離線狀態、人氣、新人標記、每分鐘點數、收藏
- 主播資料彈窗,一鍵開始視訊
- 視訊房間:本機鏡頭預覽(可關鏡頭 / 靜音)、通話計時、按分鐘扣點、文字聊天、送禮動畫
- 排行榜(日 / 週 / 月)、活動頁、每日簽到、儲值方案(示範,不扣款)
- 深色 / 淺色模式、響應式版面

所有資料只存在瀏覽器 localStorage,鏡頭畫面不會上傳。
