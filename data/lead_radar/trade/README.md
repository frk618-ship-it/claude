# 進口紀錄(在地化分數)

名單公司進口我們生產的材料時,代表它已在國外採購,是**進口替代 / 在地化**機會。把進口紀錄放在這個資料夾(`*.csv`),
商機雷達會給該公司 **在地化分數**(0–100),乘以 0.2 加入綜合分數(設定在 `config/lead_radar.yaml` 的 `settings.trade`)。

## 資料從哪裡來

台灣海關只公開「貨品(HS)× 國別」的彙總統計,**不公開哪家公司進口什麼**(關稅法第 12 條)。公司別資料可從:

- **國際貿易署 出進口廠商登記系統**(fbfh.trade.gov.tw):以貨品號列(CCC Code,例如 8108 鈦)查詢進口該貨品的廠商與進口實績級距
  (沒有逐筆金額;廠商可申請不公開)。查到的公司填一列,`value_ntd` 可留空或填級距下限。
- 付費海關 / 提單數據服務。
- 業務拜訪、詢價時客戶提供的進口來源。

## 欄位(UTF-8,第一列為欄名;「#」開頭為註解)

| 欄位 | 必填 | 說明 |
|---|---|---|
| date | ✓ | 進口月份 `YYYY-MM` 或日期 `YYYY-MM-DD` |
| company | ✓ | 公司名稱(可為全名,含名單別名即可比對,例如「台灣塑膠工業股份有限公司」→ 台塑) |
| tax_id | | 統一編號;名單公司有填 `tax_id` 時以統編精確比對 |
| hs_code | | 稅則號列,例如 `8108.90`;依前綴對應產品線(8108 鈦、7502–7508 鎳、7407–7411 銅) |
| product | | 產品線 key(`target` / `titanium` / `nickel` / `copper`);填了就不看 hs_code |
| origin | | 來源國 |
| value_ntd | | 金額(新台幣) |
| weight_kg | | 重量(公斤) |
| source | | 資料來源,會顯示在網頁 |
| note | | 備註 |

## 計分

只計最近 12 個月、且公司對該產品線適配度 ≥ 1 的紀錄:有進口 60 分;兩個以上月份 +20;合計金額 ≥ 1,000 萬元或重量 ≥ 10 公噸 +20(上限 100)。
在地化分數 × 0.2 加入綜合分數(最多 +20 分),主推產品優先選有進口的材料。沒有進口紀錄的公司不受影響。

範本:`template.csv`(只有欄名,複製後填入)。
